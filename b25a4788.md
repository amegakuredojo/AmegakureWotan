# Karasugakure — Surgical Execution Plan

## P0 — Command, Control, and Truth

### Odin
- Enforce deterministic phase transitions.
- Require explicit state checkpoint before every phase advance.
- Reject non-convergent branches after 3 retries.
- Log every decision to the audit ledger.
- Verify resume fidelity after crash recovery.

### Tyr
- Hard-block any node below threshold.
- Apply different confidence floors by source class.
- Escalate contradictions to operator decision.
- Write tentative decisions to ledger.
- Preserve rejection reasons verbatim.

### Norn
- Expand to multi-hop graph translation.
- Support temporal queries and pivot queries.
- Normalize aliases, emails, IPs, domains, onion nodes.
- Emit deterministic Cypher only.
- Reject ambiguous NL queries with structured failure.

## P1 — Graph and Correlation Depth

### Mimir
- Move from in-memory semantics to persistent graph truth.
- Enforce schema for nodes, edges, provenance, and confidence.
- Support export/import snapshots for chain-of-custody.
- Deduplicate by canonical identity key.
- Track source lineage on every edge.

### Fenrir
- Correlate shared identifiers with direction-aware rules.
- Correlate subdomains, aliases, and shared infrastructure.
- Exclude derived CORRELATED_WITH edges from future correlation loops.
- Prevent duplicate or cyclic suggestions.
- Emit correlation rationale for every link.

## P2 — Collection Agents

### Heimdall
- Normalize DNS, ASN, ports, certs, and subdomain trees.
- Rank findings by infrastructure confidence.
- Cache only signed artifacts.
- Fail closed on routing or timeout errors.
- Emit provenance for every record.

### Loki
- Resolve identities across GitHub, X, email, and usernames.
- Deduplicate alias collisions.
- Enforce rotated user-agents and process isolation.
- Tag confidence by source type.
- Record false positives for tuning.

### Hel
- Constrain onion crawling to bounded scopes.
- Track freshness and source survivability.
- Use Tor-only routing enforcement.
- Preserve retrieval context for each hit.
- Reject noisy or unstable sources.

### Skadi
- Freeze evidence immediately after acquisition.
- Hash every file, transcript, and screenshot.
- Sign bundles and dossier artifacts.
- Keep a manifest linked to the ledger.
- Verify evidence immutability on readback.

## P3 — Ledger and Chain of Custody

### Audit Ledger
- Log timestamp, agent, action, params, findings, hashes, route, previous hash.
- Use HMAC chain integrity on every block.
- Add optional clearsigning where available.
- Verify ledger on every major pipeline boundary.
- Abort on any tampering or gap.

## P4 — OPSEC and Isolation

### Network Policy
- Force Tor/proxychains for noisy collection agents.
- Separate routing profiles by agent class.
- Block network actions when route validation fails.
- Rotate UA and session identities where applicable.
- Keep process scope minimal and ephemeral.

### Runtime Isolation
- Sandbox tools in subprocesses.
- Flush memory-sensitive state on exit.
- Clear env overrides after each action.
- Disallow uncontrolled shell execution.
- Preserve only signed outputs.

## P5 — Institutionalization

### Kaisen
- Convert every completed engagement into lessons.
- Store reusable patterns by agent and source class.
- Promote validated heuristics into templates.
- Keep failed hypotheses with reasons.
- Update thresholds based on observed evidence quality.

## P6 — Validation Gates

- Smoke test every command path.
- Run controlled failure tests for ledger tamper detection.
- Run controlled offline tests for Neo4j/Memgraph fallback.
- Run controlled Tor failure tests for OPSEC blocking.
- Run controlled duplicate/cycle tests for Fenrir.
- Run controlled contradictory-source tests for Tyr.
- Run controlled resume/recovery tests for Odin.

## Execution Order
1. Harden Odin and Tyr.
2. Expand Norn and Mimir.
3. Harden Fenrir.
4. Deepen Heimdall, Loki, Hel, and Skadi.
5. Strengthen ledger and chain of custody.
6. Enforce OPSEC at runtime.
7. Institutionalize Kaisen.
8. Re-run all validation gates.
