# Karasugakure — Operating Manifest

## Core principles

1. Odin governs strategy only.
2. Norn translates intent to graph operations.
3. Mimir stores only relational truth.
4. Tyr rejects weak evidence.
5. Skadi freezes every artifact.
6. No tool touches the network without OPSEC routing.
7. No report ships without cross-validation.
8. No model is trusted without explicit role boundaries.

## Execution model

The runtime is event-driven and graph-driven. Every user command becomes a state transition. Every tool result becomes structured evidence. Every evidence item can become a node, edge, or report section.

## Agent boundaries

- Heimdall: infrastructure only.
- Loki: identities only.
- Hel: torified deep-web tasks only.
- Mimir: graph persistence only.
- Tyr: intelligence scoring only.
- Skadi: evidence immutability only.
- Fenrir: correlation only.
- Norn: language-to-graph translation only.
